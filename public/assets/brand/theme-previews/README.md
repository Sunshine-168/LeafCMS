# Bundled theme screenshots

These JPEG files show the actual homepage templates in `resources/views/themes`.
They were captured locally from a separate SQLite in-memory database populated
with `CmsSeeder` sample content. No active site settings or content were changed.

Screenshots illustrate the supplied templates, not a live hosted demo. The
`default` theme inherits the enterprise homepage by design. The screenshots use
the Chinese sample content in both language versions of the product website.

Capture date: 2026-10-24.
